# 瑞安木活字工坊地图体验

地图中 `VIII-135` 且地区/保护单位包含“瑞安”的记录，使用详情弹窗嵌入本目录 `index.html`。资源全部同源提供，不依赖 5176 开发服务或付费 API。

弹窗复用地图的遮罩、标题和关闭按钮；点击遮罩或按 Escape 返回地图。嵌入页面会通过校验来源的消息将 Escape 传给地图。

正式开发源位于 `apps/pottery/src/printing/`，与景德镇模块共用依赖。更新后的打包命令：

1. 地图根目录：`npm run build:printing`
2. 地图根目录：`npm run build`

进入后镜头从工坊走近印刷桌；“起来走走”“回到工作台”和“字墙选字”均使用连续的相机位置、朝向和视野过渡。常规过渡为 1.8 秒，系统开启“减少动态效果”时缩短至 0.2 秒。切换时不重载场景，保留手动排版、上墨及刷印进度。

复制的媒体仅包括工坊参考图、全景图和三维 SPZ；不包含生成请求、账户配置或密钥。
