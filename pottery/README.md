# 景德镇连续拉坯体验

地图项目 `VIII-7`（景德镇手工制瓷技艺）在原详情小窗口中载入本目录 `index.html`。

## 操作

- 进入后陶坯与转盘默认旋转。按住器壁左右拖动，改变所选高度附近的半径；高度滑条调节整体高度。
- “起来走走”用 1.8 秒平滑插值移动原相机，同一个 Canvas、工坊和陶坯保持挂载；回来继续原有器形。
- 漫游时 WASD/方向键移动，按住画面环顾；按钮或拉坯机提示回到制作。漫游为限定范围的数字体验，暂未加入工坊家具碰撞。
- Escape 通过同源且匹配 iframe 的消息关闭地图详情。

本版演示泥坯塑形，不模拟真人制瓷师、烧窑或成瓷。现有完整参考模型预览仍保留在 `/jingdezhen/vase.html`；可变形陶坯为独立旋转曲面，便于实时修改器形。

## 构建

正式源代码：`apps/pottery/`，已从临时目录迁入地图项目。

1. 首次在 `apps/pottery` 运行 `npm ci`。
2. 在地图根目录运行 `npm run build:pottery` 和 `npm run build`。

只打包现有本地 SPZ 和全景图，不包含账户、请求或密钥。本次没有调用生成服务。

## 近景工作区更新

2026-10-18：针对木架和原场景细边闪烁，景德镇启用 `stableEdges`：使用完整分辨率 splats、关闭动态 LOD 与点云景深、使用径向排序并增强 Gaussian 抗锯齿。临时预览入口同步相同设置。构建检查通过不代表闪烁已完成视觉核验；固定完整细节可能增加 GPU 负担。

- 新增统一的木制工作台、凳子、工具、水碗、擦布、泥屑和湿痕，并启用局部道具阴影。
- 使用 Spark 的世界坐标 SplatEdit BOX 隐藏重建区域中的旧桌面/杂物，软边为 0.06 米；远处工坊保留。
- 制作时视角收至 46 度，漫游时在 1.8 秒内扩到 60 度；相机增加轻微起身弧线，辅以短暂柔和过渡。
- 工作台加入简单的平面碰撞，防止漫游镜头穿过新桌面。原工坊其他家具尚无碰撞。
- 此轮 Vite 打包和修改文件语法检查通过；遮罩范围、实际光影和相机取景尚未完成浏览器画面核验。
